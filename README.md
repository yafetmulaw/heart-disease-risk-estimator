# ❤️ Heart Disease Risk Estimator

A machine learning web application built with **Python**, **scikit-learn**, and **Streamlit** to estimate the risk probability of heart disease using clinical and demographic indicators from the UCI Heart Disease dataset.

---

## 📁 Project Structure

```text
heart-disease-risk-estimator/
├── data/
│   └── heart.csv                 # Clean UCI Cleveland Heart Disease dataset
├── train.py                      # Model training & serialization script
├── app.py                        # Streamlit web application
├── heart_disease_model.joblib    # Exported scikit-learn pipeline (generated by train.py)
├── requirements.txt              # Project dependencies
└── README.md                     # Documentation & setup guide
```

## 🚀 Quickstart Guide

### 1. Clone & Set Up Virtual Environment

Open your terminal in the project directory:

```bash
# Create a virtual environment
python3 -m venv venv

# Activate the virtual environment
# On Linux/macOS:
source venv/bin/activate
# On Windows:
# venv\Scripts\activate
```

### 2. Install Dependencies

```bash
pip install -r requirements.txt
```

### 3. Train the Model

Run the training pipeline. This script trains a Logistic Regression classifier with feature standard scaling, evaluates performance on a stratified test set, and exports `heart_disease_model.joblib`:

```bash
python train.py
```

### 4. Launch the Streamlit Web Application

```bash
streamlit run app.py
```

Streamlit will automatically open the web app in your default browser at:
`http://localhost:8501`

## 🔬 Dataset & Clinical Features

The model uses the 13 clinical features established by the **UCI Cleveland Heart Disease** benchmark:

| Feature | Name | Clinical Description | Values / Range |
|---|---|---|---|
| `age` | Age | Patient age | 20 – 90 years |
| `sex` | Sex | Biological sex | `1` = Male, `0` = Female |
| `cp` | Chest Pain Type | Clinical classification of chest discomfort | `0` = Typical Angina, `1` = Atypical Angina, `2` = Non-anginal, `3` = Asymptomatic |
| `trestbps` | Resting Blood Pressure | Blood pressure upon hospital admission | 80 – 220 mm Hg |
| `chol` | Cholesterol | Serum cholesterol | 100 – 600 mg/dl |
| `fbs` | Fasting Blood Sugar | Blood sugar > 120 mg/dl | `1` = True, `0` = False |
| `restecg` | Resting ECG | Resting electrocardiographic reading | `0` = Normal, `1` = ST-T Wave Abnormality, `2` = LV Hypertrophy |
| `thalach` | Max Heart Rate | Peak heart rate during exercise test | 60 – 220 bpm |
| `exang` | Exercise Angina | Exercise-induced angina | `1` = Yes, `0` = No |
| `oldpeak` | ST Depression | ST depression induced by exercise vs rest | 0.0 – 6.2 mm |
| `slope` | ST Slope | Slope of peak exercise ST segment | `0` = Upsloping, `1` = Flat, `2` = Downsloping |
| `ca` | Fluoroscopy Vessels | Major vessels colored by fluoroscopy | 0 – 3 |
| `thal` | Thalassemia | Thallium stress test result | `1` = Normal, `2` = Fixed Defect, `3` = Reversible Defect |

## 💡 Web Application Features

- **Sidebar Quick Presets:** 1-click buttons to load realistic **"Low Risk"** and **"High Risk"** patient profiles for rapid testing and demonstrations.
- **Calibrated Probabilities:** Rather than a simple binary output, the app computes the continuous risk probability percentage (e.g. `12.5%` vs `88.2%`).
- **Triage Alerts:** Color-coded risk status (Low Risk 🟢, Moderate Risk 🟡, High Risk 🔴) paired with dynamic clinical feedback flags.
- **In-App Training Fallback:** If `heart_disease_model.joblib` is missing, the app provides a 1-click button to trigger training directly from the UI.
